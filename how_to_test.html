Phase 1 — Chromeに読み込む
1
拡張機能ページを開く
✓

Chromeのアドレスバーに以下を入力してEnterを押す。

① Chromeのアドレスバーをクリック
② chrome://extensions と入力
③ Enter を押す

「Chrome に追加済みの拡張機能」一覧ページが開けばOK。

2
デベロッパーモードをONにする
✓

拡張機能ページの右上に「デベロッパーモード」というトグルスイッチがある。

① 画面右上の 「デベロッパーモード」トグル を探す
② クリックしてON（青色） にする
③ ページ上部に「パッケージ化されていない拡張機能を読み込む」ボタンが出ればOK
見つからない場合： ページ右上にある小さなトグルスイッチです。ONにすると左上に3つのボタンが追加されます。
3
distフォルダを読み込む
✓

「パッケージ化されていない拡張機能を読み込む」をクリックして、ビルドされた dist/ フォルダを選択する。

① 「パッケージ化されていない拡張機能を読み込む」 をクリック
② Finder が開くので以下のフォルダを選択：
/Users/fumiyasakaino/workspace/webSticky_ver3.0/dist
③ 「開く」をクリック
④ 一覧に「WebSticky」が追加されればOK ✅
エラーが出た場合： ターミナルで npm run build を実行してから再度お試しください。

5
ライフサイクルを確認（消える・残る）
✓

付箋が正しいタイミングで残り、消えることを確認する。

✅ 残るべきケース
→ 付箋を追加した状態でページを リロード（Cmd+R）
→ 桜アイコンが有効のまま・付箋リストに付箋が残っていればOK

🗑 消えるべきケース
→ ブラウザの 「戻る」ボタン を押す → 付箋が消える
→ アドレスバーに 別のURLを入力して遷移 → 付箋が消える
  • ✓
    リロード後も付箋が残っている
  • ✓
    ブラウザバック後は付箋が消えている（桜アイコンが薄くなる）
  • ✓
    別ページへ遷移後は付箋が消えている
バックのテスト方法： ページで付箋を追加 → アドレスバーに別URLを入力して遷移 → ブラウザバックで戻る → 付箋が消えていることを確認。
