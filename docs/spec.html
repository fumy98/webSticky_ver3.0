📋 付箋リスト（0/5）
    桜アイコンをクリックしてリストを開く 付箋: 0 / 5

    🔄

    「現在地 → 戻る」で
    元の場所に戻る

    移動前のスクロール位置を記憶しているため、いつでも元に戻れる

    付箋のライフサイクル

    付箋はセッションストレージに保存されます。タブを閉じると消えますが、同じタブでのリロードは保持されます。

    操作 付箋の状態 理由
    🔄 ページをリロード 残る sessionStorageはリロードで消えないため
    ⬅️ ブラウザの「戻る」を押す 消える バックグラウンドがナビゲーションを検知してクリア
    🔗 別のページへ移動 消える URLが変わるためクリア（ページ固有の付箋のため）
    ❌ タブを閉じる 消える sessionStorageはタブを閉じると消えるため

    技術スタック

    🔷

    TypeScript

    Strictモード。型安全に実装。any型禁止。

    ⚡

    Vite

    vite-plugin-web-extensionでMV3対応のバンドルを生成。

    🗂️

    SessionStorage

    タブスコープで付箋を保存。Chrome Storage APIより軽量で即時アクセス可能。

    🌐

    Chrome MV3

    Manifest V3準拠。Background Service Worker + Content Script構成。

    🎨

    Vanilla CSS

    フレームワーク不要。z-index最大値でページ上に必ず表示。

    🌸

    SVGアイコン

    桜の花びら型アイコン。外部画像なし、軽量・スケーラブル。

    Chromeへの読み込み方

    1. ビルドする

      プロジェクトのディレクトリで npm run build を実行。dist/ フォルダが生成される。

    2. Chrome の拡張機能ページを開く

      アドレスバーに chrome://extensions と入力してアクセス。

    3. デベロッパーモードをONにする

      ページ右上の「デベロッパーモード」トグルをオンにする。

    4. 「パッケージ化されていない拡張機能を読み込む」をクリック

      ビルドで生成した dist/ フォルダを選択する。

    5. 完了！

      任意のWebページで Option+S（Mac）/ Alt+S（Windows）を押して付箋を追加してみよう。
