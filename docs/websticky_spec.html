Setup

インストール手順

Chromeにローカルインストールするだけ。ストア公開は不要。

1

依存パッケージをインストール

cd webSticky_ver3.0 npm install
2

ビルド

npm run build # → dist/ フォルダが生成される
3

Chromeに読み込む

chrome://extensions/ を開き、デベロッパーモードをONにして「パッケージ化されていない拡張機能を読み込む」から dist/ を選択。

4

使ってみる

任意のページで Option+S（Mac）/ Alt+S（Win） を押すと付箋が追加されます。右下の桜アイコンをクリックしてリストを開いてください。
