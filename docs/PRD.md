# PRD — WebSticky

## 解決する課題

- 生成AIとの会話で、気になった回答が後続のやり取りで埋もれてしまう
- 縦長LPなど、後でじっくり見返したい箇所がある
- 該当箇所へ素早く戻る手段がない

## ターゲットユーザー

- 生成AIを日常的に使うユーザー
- 縦長のWebページを閲覧するユーザー

## 機能要件

### 付箋の追加
- `Option+S`（Mac） / `Alt+S`（Windows）で現在のスクロール位置に付箋を追加
- 1ページあたり最大5枚まで

### 付箋への移動
- 画面右下に桜の花びら型アイコンを常時表示
- アイコンクリックでリストパネルを開く（1枚でもリスト表示）
- リスト内の付箋をクリックするとその位置へスクロール
- 現在地（スクロール位置）も記憶しリストに表示する

### 付箋の削除
- リストパネルから個別に削除できる

### 付箋のライフサイクル

| 操作 | 付箋の状態 |
|------|-----------|
| リロード | 残る |
| ブラウザバック | 消える |
| 別ページへ遷移 | 消える |

## 非機能要件

- Chrome拡張機能（Manifest V3）
- 既存ページのレイアウトを崩さない
- 軽量・シンプルな実装

## スコープ外（将来対応）

- Firefox対応
- 右クリックメニューからの付箋追加
- 付箋へのメモ機能
- 付箋の色変更
