Privacy Policy

🔒 一言まとめ

🔒 Summary

WebSticky はあなたの個人情報を一切収集しません。すべてのデータはあなたのブラウザ内にのみ保存されます。

WebSticky does not collect any personal information. All data is stored locally in your browser only.

✅ 収集なし / No data collected ✅ 外部送信なし / No external transmission ✅ 第三者提供なし / No third-party sharing

📋 収集するデータ

📋 Data Collection

WebSticky は以下のデータを一切収集しません：

WebSticky does not collect any of the following:

  • 個人を特定できる情報（氏名、メールアドレス等）
  • Personally identifiable information (name, email, etc.)
  • 閲覧したURLや履歴
  • Browsing history or visited URLs
  • 入力フォームの内容
  • Form input data
  • クッキーやトラッキング情報
  • Cookies or tracking data

💾 データの保存について

💾 Data Storage

拡張機能の動作に必要な以下のデータのみを、ユーザーのブラウザ内に保存します。外部サーバーへの送信は一切行いません。

Only the following data required for the extension to function is stored locally in your browser. No data is sent to any external server.

保存するデータ Data Stored 保存場所 Storage 用途 Purpose
付箋のスクロール位置 Sticky note scroll positions sessionStorage sessionStorage ページ内の付箋位置を記憶するため To remember sticky positions within the page
桜UIの表示位置 Sakura UI position localStorage localStorage ユーザーがドラッグした位置を維持するため To persist user's dragged position

🛡️ 要求する権限の理由

🛡️ Why These Permissions

権限 Permission 必要な理由 Reason
host_permissions: <all_urls> host_permissions: <all_urls> どのWebページでも付箋UIを表示するため。データ収集目的ではありません。 To display the sticky UI on any webpage. Not for data collection.
webNavigation webNavigation ページ遷移を検知し、適切なタイミングで付箋データをクリアするため。 To detect page navigation and clear sticky data at the appropriate time.

🤝 第三者への提供

🤝 Third-Party Sharing

収集したデータはありません。したがって、第三者へのデータ提供も行いません。広告・アナリティクス・外部サービスとの連携は一切ありません。

We do not collect any data. Therefore, no data is shared with any third parties. There is no integration with advertising, analytics, or external services.
