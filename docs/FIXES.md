# FIXES — WebSticky v3.0

## バグ修正

- [x] **B1** — `floatButton.ts`: `disabled` クラスがあってもクリックを防げていない
  - 付箋0枚のときボタンを押すと空のパネルが開いてしまう
  - 修正：クリックハンドラ内で `count === 0` のときは早期リターン

- [x] **B2** — `content/index.ts`: Alt+S で付箋追加後に `renderPanel` を呼んでいない
  - パネルが開いた状態で付箋を追加しても表示が更新されない
  - 修正：`addSticky()` 成功後に `renderPanel(getStickies(), getCurrentY())` を追加

- [x] **B3** — `content/index.ts`: `CLEAR_STICKIES` 受信時にパネルを閉じていない
  - 別ページへ遷移・ブラウザバック後もパネルが開いたまま残る可能性がある
  - 修正：メッセージ受信時に `hidePanel()` と `renderPanel([], 0)` を呼ぶ

## UX 改善

- [x] **U1** — Alt+S で付箋追加したときに画面上のフィードバックがない
  - 現状は `console.info` のみで、ユーザーが追加できたか判断できない
  - 修正：トースト通知（例:「📌 付箋を追加しました（2/5）」）を表示する

- [x] **U2** — 5枚上限に達したときに視覚的なフィードバックがない
  - 修正：上限到達時のトースト（例:「付箋は最大5枚までです」）を表示する
